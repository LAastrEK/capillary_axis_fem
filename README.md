# Capillary Axisymmetric FEM Model

2D осесимметричная модель микрофлюидного капилляра для симуляции инжекции и аспирации жидкости в чашке Петри с клетками.

## Что моделирует

- Двухстадийный протокол: инжекция - аспирация
- Физические поля: скорость, давление, напряжения сдвига, завихренность
- Критические параметры: застойные зоны, пиковый сдвиг на клетках, баланс масс
- Геометрия: плавный переход от узкого сопла к широкому телу капилляра

## Требования

- Docker Desktop
- Или Python 3.8+ с FEniCS, Gmsh, meshio (для локального запуска)

## Запуск через Docker

### 1. Сборка образа (Powershell в корневой папке)

```
docker build -t capillary-axis-fem .
```
2. Запуск симуляции

```
# Основная симуляция (с пересозданием сетки)
docker run --rm -v ${PWD}:/app capillary-axis-fem python3 run_simulation.py --remesh
```

### 3. Настройка параметров

Параметры задаются в `config.py` или через командную строку:

```
# Пример: доза 5 мкл, зазор до клеток 0.2 мм
docker run --rm -v ${PWD}:/app capillary-axis-fem python3 run_simulation.py \
  --dose-ul 5 \
  --standoff-mm 0.2 \
  --u-inj-mm-s 5.0 \
  --u-asp-mm-s 5.0
```

Доступные параметры:
- `--dose-ul` — объем дозы (мкл)
- `--standoff-mm` — расстояние от кончика до дна (мм)
- `--u-inj-mm-s` — скорость инжекции (мм/с)
- `--u-asp-mm-s` — скорость аспирации (мм/с)
- `--R-mm` — радиус расчетной области (мм)
- `--lc-nozzle-um` — размер ячейки у сопла (мкм)
- `--no-inertia` — отключить инерцию (решать Стокс вместо Навье-Стокса)

## Результаты

После запуска в папке `output/` появляются:

- `metrics.json` — все физические метрики (расходы, давления, сдвиг, Re)
- `speed_full_injection.png` / `speed_full_aspiration.png` — поля скоростей (полное сечение)
- `velocity_*.pvd`, `pressure_*.pvd` — файлы для ParaView
- `mesh.xdmf` — сетка

## Структура проекта

```
capillary_axis_fem/
├── config.py           # Параметры модели
├── geometry.py         # Геометрия капилляра
├── meshing.py          # Генерация сетки (Gmsh)
├── solver.py           # FEM решатель (FEniCS)
├── metrics.py          # Расчет метрик
├── postprocess.py      # Визуализация
├── verification.py     # Тест Пуазейля
├── run_simulation.py   # Главный скрипт
└── Dockerfile          # Образ Docker
```

## Основные метрики

- Q_inner, Q_annular — расходы через каналы (м³/с)
- gamma_max_cell — максимальный сдвиг на клетках (1/с)
- k_stag_percent — доля застойных зон (%)
- Re_jet — число Рейнольдса струи
- t_phase_s — время фазы для заданной дозы (с)
- port_continuity_rel_err — ошибка баланса расхода (должна быть < 1e-8)
